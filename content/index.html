Sea's Voice

A cinematic Jarvis voice via ElevenLabs. Pick a voice and press Test.

Free ElevenLabs plan works for testing. If the key is empty, Sea falls back to the built-in Mac voice.

📧

Connect Gmail

So Sea can send email on your behalf. Uses a Google App Password — no Google Cloud setup.

Get an App Password: Google Account → Security → 2-Step Verification (on) → App passwords. Stored only on this Mac.

💬

Connect Slack

So Echo can send and search your Slack. Paste a Slack token (starts with xoxp- or xoxb-).

Get a token at api.slack.com/apps → create an app → OAuth & Permissions → add scopes (chat:write, search:read, channels:read, users:read) → Install → copy the token. Stored only on this Mac.

🧠 Memory

    Stored encrypted on this Mac (Keychain). Values are never shown or sent to the AI.
